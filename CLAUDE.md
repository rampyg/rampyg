# Project memory

## Writing style for social posts (LinkedIn / X) and marketing copy
- Do not use adverbs in the posts.
- No em-dashes (and no en-dashes used as dashes).
- Plain, human language. Should not read as AI-generated.
- Structure each concept post failure-first: open with a concrete failure, then the design that solves it.
- Gloss every technical term in plain words the first time it appears.
- X posts stay at or under 280 characters (URL counts as 23, @mention as its literal length). Verify the count.
- Convention: X posts link to github.com/vouch-protocol/vouch (tag @Vouch_Protocol); LinkedIn posts link to vouch-protocol.com.
- Ground all public copy in the public OSS repo (vouch-protocol/vouch). Never use the private Pro repo (rampyg/vouch-protocol-pro) for public copy.
