# Project memory

## Writing style for social posts (LinkedIn / X) and marketing copy
- No adverbs.
- No em-dashes (and no en-dashes used as dashes).
- No hyperbole. Avoid phrases like "game over," "the whole ballgame," "crown jewel."
- No jargon and no acronyms in the body. Spell things out or describe them in plain words: say "a public ID anyone can look up," not the acronym; "a sealed chip built into the machine," not the chip's technical name. Avoid code identifiers and standard names; describe what they do.
- Plain, human language. Should not read as AI-generated.
- Logical flow: each concept builds step by step, so a reader with no background can follow it.
- Structure each concept failure-first: open with a concrete failure, then the design that solves it.
- LinkedIn: a few short paragraphs, room to explain.
- X: publish each concept as a THREAD, not a single compressed post. A single 280-character post is too cryptic for a concept. First tweet is a concrete failure hook with no link. One idea per tweet, plain language, logical flow. Put the link in the final tweet. Each tweet stays at or under 280 characters (URL counts as 23, @mention as its literal length); verify the count.
- Convention: X links to github.com/vouch-protocol/vouch (tag @Vouch_Protocol); LinkedIn links to vouch-protocol.com.
- Ground all public copy in the public open-source repo (vouch-protocol/vouch). Do not use the private Pro repo (rampyg/vouch-protocol-pro) for public copy.
